# Cérebro — guias de estudo de Engenharia

Guias de estudo abertos e gratuitos: resoluções passo a passo, formulários
organizados e roteiros de revisão escritos durante o estudo das disciplinas.

**Site:** https://SEU-USUARIO.github.io/cerebro/

## O que tem aqui

| Guia | Disciplina | O que é |

Cada guia é um arquivo HTML único e autocontido — todo o CSS está embutido, e
as únicas dependências externas são Google Fonts e MathJax (via CDN). Não há
build: dá para abrir qualquer arquivo direto no navegador, sem servidor.

## O que **não** entra neste repositório

Este repositório é público, então ele contém apenas material autoral.

Livros-texto, slides de aula dos professores, provas oficiais e digitalizações
de qualquer natureza **não** entram — redistribuir esse material é violação de
direito autoral. O [`.gitignore`](.gitignore) bloqueia os formatos
correspondentes (`.pdf`, `.epub`, `.pptx`, ...) como segunda linha de defesa,
mas a primeira é esta: não copie esses arquivos para cá.

## Aviso

São anotações de estudante, escritas para estudar. Não são material oficial de
nenhuma disciplina e não substituem o livro-texto nem as aulas. Encontrou um
erro? Abra uma issue — correção é bem-vinda.

## Como contribuir

1. Abra uma issue descrevendo o erro ou a sugestão.
2. Para corrigir você mesmo: fork, edite o HTML do guia e abra um pull request.
3. Guias novos seguem o mesmo padrão — arquivo único, CSS embutido, os mesmos
   tokens de cor e tipografia do [`index.html`](index.html).
